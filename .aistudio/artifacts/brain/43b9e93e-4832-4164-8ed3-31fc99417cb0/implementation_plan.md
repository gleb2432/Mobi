# Модуль экспорта отчетов в Excel и PDF по остаткам стеклотары и партиям FIFO

План добавления профессионального генератора и экспорта складских отчетов (ведомость остатков, отчет по партиям FIFO, детализация по рядам и локациям) с выгрузкой в Excel и готовыми для печати / сохранения в PDF формами.

## User Review & Critical Decisions

> [!IMPORTANT]
> На основе вашего ответа в приоритет выбран **экспорт отчетов в Excel и PDF по остаткам и партиям**.

- **Подтвержденное решение**:
  - Экспорт сводной ведомости остатков (по сортам бутылок, поставщикам, цветам, общему числу паллет и бутылок).
  - Экспорт детальной ведомости партий (номер ячейки, дата производства, возраст партии, номер ТС, статус блокировки).
  - Форматы: **Excel** (прямая выгрузка структурированной таблицы с русскими заголовками и итогами) и **PDF / Печать** (официальный бланк складской ведомости с датой, подписью оператора и книжной/альбомной версткой).
- **Расположение в интерфейсе**:
  - Быстрая кнопка экспорта в шапке раздела **«Схема Рядов»** и вкладке **«Завоз FIFO»** для кладовщиков.
  - Расширенный центр отчетов в **«Админ панели»** с фильтрацией по локациям (Эстакада, Плиты, АБК), датам и статусу ячеек.

## 1. Overview & Core Concept

- **Что делает**: Предоставляет кладовщикам, логистам и руководству возможность в один клик формировать актуальные официальные отчеты по движению и запасам стеклотары на терминале.
- **Для кого**: Начальники смен, кладовщики, операторы погрузчиков и бухгалтерия/отдел снабжения завода.
- **Ключевая ценность**:
  1. Избавляет от ручного пересчета ячеек и ведения бумажных журналов.
  2. Готовая таблица Excel для анализа оборачиваемости и сверки с заводами-поставщиками стеклотары.
  3. Четкий печатный бланк (PDF) для выдачи водителям и прикрепления к сменным накладным.

## 2. User Experience & Visual Design

### Ключевые пользовательские сценарии

1. **Экспресс-экспорт остатков в Excel:**
   - Пользователь нажимает кнопку **«Экспорт отчета»** (рядом с кнопкой фильтрации сортов).
   - Появляется диалоговое окно с выбором отчета:
     - *«Сводная ведомость по сортам и поставщикам»*
     - *«Детальная ведомость по ячейкам и партиям (FIFO)»*
     - *«Журнал перемещений и завоза на склад»*
   - Скачивается файл Excel с понятным именем (например: `Остатки_Стеклотары_Эстакада_2026-10-27.xlsx`).

2. **Формирование печатного отчета / PDF:**
   - Нажатие кнопки **«Печать / PDF»** открывает предпросмотр официального документа.
   - Документ содержит:
     - Шапку предприятия (Терминал Стеклотары, дата и время среза остатков, ответственный оператор).
     - Сводные KPI (Всего ячеек, занято, свободно, общее число паллет, ориентировочное число бутылок).
     - Таблицу с четкой разметкой (Ряд, Ячейка, Сорт тары, Цвет, Поставщик, Дата выработки, Возраст в днях, Количество паллет).
     - Блок подписей («Сдал смену: ____________», «Принял: ____________»).
   - Нажатие **«Распечатать / Сохранить как PDF»** вызывает системный диалог с оптимизированными стилями `@media print`.

### Визуальный стиль
- **Интерфейс приложения**: Сохранение монохромной индустриальной темы Dark Slate (`bg-slate-950`) с изумрудными акцентами (`text-emerald-400`, `border-emerald-800`), четкими моноширинными шрифтами для чисел и кодов ячеек (`font-mono tabular-nums`).
- **Печатный бланк (Print/PDF)**: Строгий, высококонтрастный бело-черный бланк с аккуратными тонкими линиями таблиц, четкими шрифтами без засечек и продуманным размещением на одном или двух листах A4.

## 3. Key Product Decisions & Trade-Offs

- **Решение 1: Генерация Excel на клиенте без передачи данных сторонним сервисам**
  - *Выбор*: Использование легковесной библиотеки генерации Excel (`xlsx`) или специализированного генератора XML-Spreadsheet/CSV с BOM.
  - *Причина*: Полная автономность в браузере, отсутствие задержек сервера, безопасность складских данных, мгновенное скачивание.
- **Решение 2: Печать и сохранение в PDF через стандартизированный print-view**
  - *Выбор*: Выделенный компонент складской ведомости с CSS `@media print` и стилями альбомной ориентации.
  - *Причина*: Идеальное качество векторного PDF на любых устройствах (iOS, Android, ПК), встроенная поддержка любого принтера без артефактов растеризации.

### Структура выгружаемых отчетов

1. **Сводный отчет по сортам тары (Таблица 1):**
   - Наименование бутылки
   - Цвет стекла
   - Поставщик
   - Количество занятых ячеек
   - Всего паллет
   - Всего бутылок (штук)
   - Самая старая партия на остатке (дата и дней хранения)

2. **Поячеечная ведомость размещения (Таблица 2):**
   - Локация (Эстакада / Плиты / АБК)
   - Номер ячейки (например: `A1`, `B4`, `M2`)
   - Номер ТС (госномер машины)
   - Наименование бутылки и поставщик
   - Партии и даты производства
   - Фактическое количество паллет / Вместимость ячейки
   - Статус (В норме / Заблокировано с указанием причины)
